# Abdul Malik Pasha | DevOps Engineer Portfolio

A modern personal portfolio website built with HTML, CSS, and JavaScript to showcase the professional profile, skills, certifications, experience, and achievements of Abdul Malik Pasha.

## Live Preview

Open the project in a browser after starting a local server:

```bash
python -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```

## Project Structure

```text
About-me/
├── index.html
├── styles.css
├── script.js
├── README.md
└── .git/
```

## Files Overview

- `index.html` — Main structure and content for the portfolio page
- `styles.css` — All styling, layout, animations, and responsive design
- `script.js` — Scroll reveal animation and dynamic year update

## Features

- Modern dark-themed professional landing page
- Responsive layout for desktop and mobile devices
- Smooth section animations on scroll
- Experience timeline and skill tag sections
- Contact links for LinkedIn, email, and phone
- Clean and recruiter-friendly design

## Customization

You can update the personal details in `index.html` such as:

- Name
- Role
- Email
- Phone
- LinkedIn URL
- Work experience details
- Skills and certifications

## Local Run

From the project folder:

```bash
python -m http.server 8000
```
